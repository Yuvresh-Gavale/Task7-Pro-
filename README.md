# Responsive Laundry Services

A responsive laundry services landing page built using **HTML and CSS**.
The project demonstrates responsive web design using **CSS Flexbox** and media queries for different screen sizes.

## Features

* Responsive Flexbox navbar
* Responsive hero section
* Laundry services call-to-action
* Responsive layout for desktop, tablet, and mobile
* Media queries for different screen sizes
* Hover effects and smooth CSS transitions
* Clean and simple HTML structure

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

## Responsive Breakpoints

The website uses CSS media queries for:

* Desktop: Above 768px
* Tablet: 768px and below
* Mobile: 480px and below

## Learning Objective

The main objective of this task is to understand how to create a responsive webpage using **Flexbox**, media queries, and responsive sizing techniques.
